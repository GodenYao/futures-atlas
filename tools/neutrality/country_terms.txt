# Country names, nationalities and capital metonyms. The map and the public ledger show blocs
# (Bloc A, Bloc B, ...), never countries.
#
# Used by:
#   tools/validate_evidence.mjs  - WARNING if a term appears in summary / reasoning / counterpoint
#                                  (the reviewer agent rewrites it to a bloc label before merge)
#   tools/anonymize.mjs          - rewrites every term of a group to that group's bloc label,
#                                  using a PRIVATE mapping file passed on the command line
#
# Format: one group per line, terms separated by "|". The first term names the group (the
# entity); the others are abbreviations, demonyms / adjectives and capital metonyms for it.
# A trailing "@supranational" marks a group that is not a country: anonymize.mjs maps it only
# if the private mapping lists it (or with --assign-supranational).
# Matching is whole-word. The validator matches case-insensitively; anonymize.mjs matches the
# written case or ALL CAPS. Short ALL-CAPS abbreviations always match case-sensitively so
# ordinary words such as "us" are fine. '#' starts a comment.
# This is the ONLY file in the repo that may list country names. Maintainers may add terms;
# a change here is logged in CHANGELOG.md.
